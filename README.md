# Sync Music

Синхронизация музыки с компьютера (Windows) на телефон (Android) по Wi-Fi в домашней сети. Без облака и без лимитов на объём.

- **На компьютере** работает программа Sync Music. Она отдаёт телефону папку с музыкой и показывает по каждому телефону, сколько уже синхронизировано, сколько осталось, скорость и примерное время до конца.
- **На телефоне** приложение работает в фоне: каждые 15 минут проверяет, включён ли компьютер, докачивает новое и удаляет то, что удалили на ПК. Музыка лежит в `Music/Sync Music`, её видят все плееры.

## Установка

1. Откройте [последний релиз](../../releases/latest).
2. **Компьютер:** скачайте `SyncMusic-x.y.z.msi` и запустите. Права администратора не нужны. Если установщик не подходит, распакуйте `SyncMusic-x.y.z-portable.zip` и запустите `SyncMusic.exe`.
   - При первом запуске Windows может спросить про доступ к сети: нажмите **«Разрешить доступ»**.
3. **Телефон:** наведите камеру телефона на QR-код в окне программы на ПК, скачайте и установите приложение (Android попросит разрешить установку из браузера).
4. В приложении на телефоне нажмите **«Найти компьютер»**, выберите свой ПК и введите 6-значный код с экрана компьютера.
5. Дайте приложению разрешения: «Доступ ко всем файлам» (чтобы класть музыку в папку Music) и «Работа в фоне».

Дальше всё работает само. Обновления: новая версия программы для ПК приносит с собой и новую версию приложения, а телефон сам предложит обновиться.

## Если телефон не находит компьютер

- Телефон и компьютер должны быть в одной Wi-Fi сети, без гостевой сети и без режима «изоляции клиентов» в роутере.
- В программе на ПК нажмите **«Разрешить в брандмауэре»** (Windows попросит подтверждение администратора).
- Можно ввести адрес вручную: он показан в окне программы на ПК («Адрес компьютера для ручного ввода»).

## Как это устроено

| Часть | Технологии |
|---|---|
| ПК | Kotlin + Compose Desktop, встроенный HTTP-сервер Ktor (порт 45456), UDP-обнаружение (порт 45455), иконка в трее, автозапуск |
| Телефон | Kotlin + Jetpack Compose, WorkManager (фоновая работа, foreground service типа dataSync), OkHttp |
| Общее | Модуль `shared`: протокол и форматирование |

Протокол:

1. Телефон рассылает UDP-broadcast `SYNCMUSIC_DISCOVER_V1`, компьютер отвечает своим именем и портом.
2. Сопряжение: телефон отправляет одноразовый 6-значный код с экрана ПК и получает постоянный токен.
3. Синхронизация: `GET /api/manifest` (список файлов с размером и датой) → сравнение с телефоном → `GET /api/file` с докачкой через HTTP Range → `POST /api/progress` каждую секунду, чтобы ПК показывал прогресс.

Синхронизация односторонняя: компьютер → телефон. Удаляются только файлы, которые загрузило само приложение. Если папка с музыкой на ПК недоступна, телефон ничего не удаляет.

## Сборка

Собирается автоматически в GitHub Actions при каждом пуше в `main`: APK (Ubuntu) → вкладывается в программу для ПК → MSI и portable-zip (Windows) → релиз `v1.0.<номер сборки>`. Логи последней сборки лежат в ветке `ci-logs`.

Локально (JDK 17, Android SDK):

```
./gradlew :androidApp:assembleRelease
./gradlew :desktopApp:run
```
